# Procedencia y comparación

Versión de portafolio basada en una automatización aplicada a un caso real.

Se inspeccionaron dos archivos locales llamados `main.py` y el código recuperado aportado por el autor. La versión de 335 líneas contiene controles que no aparecen en la de 200 líneas: validación completa del JSON, protección CSV, seguimiento de Azure en el mismo origen, comprobación de páginas, reintentos y salidas de auditoría. También conserva las instrucciones detalladas para interpretar áreas, monedas y unidades japonesas. Se eligió por esas diferencias verificadas, no por su fecha de modificación.

Portfolio refactor: empaquetado, configuración de ejemplo, exclusiones, datos ficticios, documentación y tests añadidos posteriormente. No se atribuyen estas mejoras al desarrollo original. El algoritmo recuperado se conserva con autorización del autor para esta publicación. No se identificaron fragmentos de código propietario de terceros en el archivo revisado. No se incluyen PDFs ni resultados del caso real y no se asigna una licencia.
